# Typography

Pairing A is the one in the product.

- Display: Newsreader, weights 400 and 600, italic included, optical sizes left to the font.
- Interface: Hanken Grotesk, weights 400, 500, and 600.
- Codes and times: IBM Plex Mono, weights 400 and 500.

Reasons: the screenshots use a serif for the page title and a plain sans for the rest. Newsreader is a text serif with tabular figures, not a display costume. Hanken Grotesk stays neutral at 12px. IBM Plex Mono keeps project codes readable. All three are free, Latin, and loaded with `next/font` and `display: swap`.

Pairings B and C are on `/typography`. A production build replaces that page with a short note so the specimen is not part of the product. Fragment Mono is not in the Google font set used by `next/font` here, so pairing C uses IBM Plex Mono for the code line.

Banned defaults (Inter, Roboto, Geist, Space Grotesk, DM Sans, Poppins, Plus Jakarta Sans, Instrument Serif, Playfair Display, Fraunces, JetBrains Mono) are not used.
