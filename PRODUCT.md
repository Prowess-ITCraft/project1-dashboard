# Product

Project One is an internal operations dashboard for ITCraft. It turns a customer purchase order into a checked delivery: intake, kick-off, planning, execution, and closure, ending in a completion certificate.

The people using this preview are directors, project managers, and verifiers. Field engineers appear as the work being watched, not as the audience of this screen.

This build is a mock-data preview. It has to feel like the finished product: calm, precise, and dense enough to scan, with a login that states the promise in one line: Order. Configure. Prove.
